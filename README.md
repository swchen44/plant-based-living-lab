# Plant-Based Living Lab

高中自主學習研究探索平台，繁體中文靜態網站。

## 網站內容

- 從素食家庭生活出發的 Brainstorming
- 16 個研究問題群的 SVG 心智圖與網站架構圖
- 三學期規劃：每學期四個候選、最終選兩題（尚未選定）
- 01–12：營養、食品AI、校園、經濟、材料、乳液、保存、碳排、文化、地圖、創業、AI顧問
- 13–16：陽台蔬果、自然光與LED、DIYGreen循環節水、智慧陽台農場
- 每題研究問題、實作流程、預期成果與量化驗證
- 16 張 SVG 概念插畫、互動篩選與搜尋

## GitHub Pages

在 Settings → Pages 設定 Deploy from a branch，選 main 與 /(root)。
